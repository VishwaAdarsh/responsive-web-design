# Week 2 — Responsive Web Design

## Project
Aster Studio — Responsive Digital Product Studio

## Objective
Convert the Week 1 static webpage into a responsive website that adapts across desktop, tablet, mobile and small-mobile viewports.

## Technologies
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- `clamp()`, `min()`, flexible grid tracks
- Responsive images

## Responsive Strategy
- Desktop: two-column hero, three-column services, four-column footer.
- Tablet: two-column services and footer.
- Mobile: single-column hero, services, about and footer.
- Small mobile: tighter navigation and stacked newsletter form.

## Suggested Tests
1440×900, 1280×720, 1024×768, 768×1024, 430×932, 390×844, 375×667.
